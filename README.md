# Campus Trading App

A database-backed campus marketplace for students to buy, sell, and trade items (e.g. books, electronics, furniture) within the campus community.

## Contents

| Folder | Description |
|--------|-------------|
| **[Assignment_1](./Assignment_1/)** | Database design and implementation: schema, sample data, UML diagrams, and documentation. |
| **[Assignment_2](./Assignment_2/)** | Full-stack application: Go backend with MySQL, React frontend, admin audit log, and member seeding and B+ Tree implementation for efficient product search. |

## Quick start

1. Go to **[Assignment_1](./Assignment_1/)** and read its README.
2. Run the SQL script in a MySQL 8.0+ client to create the database and load sample data.
3. Go to **[Assignment_2](./Assignment_2/)** and for Module-A go to **[Module_A](./Assignment_2/Module_A/)** and read its README. Then for Module-B go to **[Module_B](./Assignment_2/Module_B/)** and read its README.
4. Start the Go backend and React frontend as described in the Assignment 2 README.

## Tech

- **DBMS:** MySQL 8.0+ (InnoDB, utf8mb4)
- **Backend:** Go (Assignment 2)
- **Frontend:** React (Assignment 2)
- **Deliverables:** SQL DDL/DML, UML (Mermaid), design doc, full-stack web app
